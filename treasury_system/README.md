# 💰 نظام الخزينة المتطور - Treasury Management System

نظام إدارة خزينة احترافي مع واجهة عصرية ونظام هرمي متقدم للخزائن والعملاء والموردين.

## 🌟 المميزات الرئيسية

### 🏗️ النظام الهرمي المتقدم
- **الخزائن المتدرجة**: خزائن رئيسية (حاوية) وفرعية مع حساب تلقائي للأرصدة
- **العملاء الهرميين**: شركات رئيسية وفروعها
- **الموردين الهرميين**: مجموعات موردين وفروعهم
- **منع المعاملات المباشرة** على الحاويات/المجموعات

### 🎨 واجهة مستخدم عصرية
- **سايد بار احترافي** قابل للطي مع أنيميشن سلس
- **لوحة تحكم تفاعلية** مع إحصائيات حية
- **رسوم بيانية** لعرض البيانات
- **تصميم متجاوب** يعمل على جميع الأجهزة

### 📊 نظام السندات المتكامل
- سندات قبض وصرف
- تحويلات بين الخزائن
- ترقيم تلقائي للسندات
- ربط السندات بالعملاء والموردين

### 📈 التقارير المتقدمة
- كشف حساب العملاء والموردين
- حركة الخزائن اليومية
- تقارير الأرباح والخسائر
- تصدير PDF و Excel

## 🚀 التشغيل السريع

### المتطلبات
- Python 3.11+
- PostgreSQL أو SQLite

### التثبيت

```bash
# استنساخ المشروع
git clone [repository-url]
cd treasury_system

# تثبيت المكتبات
pip install -r requirements.txt

# إعداد قاعدة البيانات
export DATABASE_URL='postgresql://user:pass@host/dbname'
python migrate_hierarchical.py

# تشغيل التطبيق
python app.py
```

### الوصول للنظام
افتح المتصفح على: http://localhost:5000

```
خزينة السلام (حاوية) - 50,000 ج.م
├── صندوق المبيعات النقدية - 20,000 ج.م
├── صندوق مبيعات الفيزا - 15,000 ج.م

```
مجموعة الأمل التجارية (مجموعة)

## 🔑 API Endpoints

### الخزائن
- `GET /api/safes` - قائمة الخزائن
- `POST /api/safes` - إضافة خزينة
- `GET /api/safes/tree` - الخزائن بشكل هرمي

### العملاء
- `GET /api/customers` - قائمة العملاء
- `POST /api/customers` - إضافة عميل
- `GET /api/customers/tree` - العملاء بشكل هرمي

### الموردين
- `GET /api/suppliers` - قائمة الموردين
- `POST /api/suppliers` - إضافة مورد
- `GET /api/suppliers/tree` - الموردين بشكل هرمي

### السندات
- `GET /api/vouchers` - قائمة السندات
- `POST /api/vouchers` - إضافة سند

## 📝 ملاحظات مهمة

- **الخزائن الحاوية**: لا تقبل معاملات مباشرة، رصيدها = مجموع الفرعيات
- **المجموعات**: العملاء والموردين المجموعات لا يمكن إجراء معاملات مباشرة معهم
- **الترقيم التلقائي**: جميع السندات تحصل على أرقام تلقائية (REC/PAY/TRN)
