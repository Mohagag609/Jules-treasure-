# نظام الخزينة المتكامل 💰

نظام خزينة احترافي ومتكامل لإدارة الحسابات المالية للشركات والمحلات التجارية.

## المميزات الرئيسية 🌟

### 1. إدارة شاملة
- **العملاء والموردين**: تسجيل وإدارة بيانات العملاء والموردين مع متابعة الأرصدة
- **الخزائن المتعددة**: خزينة رئيسية وخزائن فرعية مع إمكانية التحويل بينها
- **السندات المالية**: سندات قبض وصرف مترابطة مع ترقيم تلقائي

### 2. سهولة الإدخال ⚡
- **إدخال سريع**: نموذج إدخال سريع في الصفحة الرئيسية
- **اختصارات لوحة المفاتيح**: 
  - `Alt+N`: سند جديد
  - `Alt+C`: البحث عن عميل
  - `Alt+S`: البحث عن مورد
  - `Alt+M`: التركيز على المبلغ
  - `Enter`: حفظ السند
- **إكمال تلقائي**: للعملاء والموردين أثناء الكتابة

### 3. التقارير المتقدمة 📊
- تقارير يومية/شهرية/سنوية
- كشف حساب العملاء والموردين
- رصيد سابق قبل تاريخ أو سند معين
- تقرير الأرباح والخسائر
- تصدير PDF و Excel

### 4. لوحة تحكم ذكية 📈
- إحصائيات لحظية
- رصيد الخزائن
- حركة اليوم
- آخر السندات

## التثبيت والتشغيل 🚀

### التشغيل المحلي

1. **تثبيت المتطلبات**:
```bash
cd treasury_system
pip install -r requirements.txt
```

2. **تشغيل البرنامج**:
```bash
python app.py
```

3. **فتح المتصفح**:
```
http://localhost:5000
```

### النشر على Render

1. **إنشاء حساب على Render**:
   - اذهب إلى [render.com](https://render.com)
   - سجل حساب جديد

2. **رفع المشروع على GitHub**:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin YOUR_GITHUB_REPO_URL
git push -u origin main
```

3. **النشر على Render**:
   - اضغط "New +" واختر "Web Service"
   - اربط مع مستودع GitHub
   - اختر المستودع الخاص بك
   - Render سيكتشف الإعدادات تلقائياً من `render.yaml`
   - اضغط "Create Web Service"

4. **الانتظار حتى اكتمال النشر**:
   - Render سينشئ قاعدة بيانات PostgreSQL تلقائياً
   - سيثبت المتطلبات ويشغل التطبيق
   - ستحصل على رابط مثل: `https://treasury-system.onrender.com`

## الاستخدام 📝

### إضافة سند سريع
1. اختر نوع السند (قبض/صرف/تحويل)
2. ابدأ بكتابة اسم العميل أو المورد
3. اختر الخزينة
4. أدخل المبلغ
5. اضغط Enter للحفظ

### عرض التقارير
1. اذهب لتبويب التقارير
2. اختر نوع التقرير
3. حدد الفترة الزمنية
4. اضغط "عرض التقرير"

## التقنيات المستخدمة 💻
- **Backend**: Python Flask
- **Database**: SQLite (محلياً) / PostgreSQL (Render)
- **Frontend**: HTML5, Bootstrap 5, JavaScript
- **Charts**: Chart.js
- **Tables**: DataTables
- **Icons**: Bootstrap Icons
