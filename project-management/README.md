# نظام إدارة المشاريع والشركاء

نظام متكامل لإدارة المشاريع والشركاء والموردين مع حساب التسويات التلقائية.

## المميزات الرئيسية

✅ **نموذج إدخال موحد**: إدخال جميع البيانات من واجهة واحدة
✅ **حساب تلقائي للتسويات**: تسوية الحسابات بين الشركاء تلقائياً
✅ **إدارة المراحل**: تتبع مراحل المشروع المختلفة
✅ **إدارة الشركاء**: تسجيل الشركاء ونسبهم ومدفوعاتهم
✅ **إدارة الموردين**: تتبع المدفوعات للموردين
✅ **تقارير شاملة**: عرض تفصيلي للحسابات والأرصدة
✅ **واجهة عربية حديثة**: تصميم سهل الاستخدام باللغة العربية

## التقنيات المستخدمة

- **Next.js 15**: إطار عمل React للتطبيقات الحديثة
- **TypeScript**: للكتابة الآمنة للأكواد
- **SQLite**: قاعدة بيانات محلية سريعة
- **Tailwind CSS**: للتصميم السريع والجميل
- **React Hook Form**: لإدارة النماذج

## تشغيل المشروع

### المتطلبات
- Node.js 18 أو أحدث
- npm أو yarn

### خطوات التشغيل

1. **تثبيت المكتبات**:
```bash
npm install
```

2. **تشغيل خادم التطوير**:
```bash
npm run dev
```

3. **فتح التطبيق**:
افتح المتصفح على العنوان: [http://localhost:3000](http://localhost:3000)

## كيفية الاستخدام

### 1. إضافة مرحلة جديدة

1. اضغط على "إدخال جديد" من القائمة العلوية
2. أدخل بيانات المرحلة:
   - اسم المرحلة (مثل: الأساسات)
   - المبلغ الإجمالي للمرحلة

### 2. إضافة الشركاء

1. أدخل أسماء الشركاء
2. حدد نسبة كل شريك (يجب أن يكون المجموع 100%)
3. أدخل المبلغ المدفوع من كل شريك

### 3. إضافة الموردين

1. أدخل أسماء الموردين
2. حدد المبالغ المدفوعة لكل مورد

### 4. حفظ وحساب التسويات

- اضغط على زر "حفظ وحساب التسويات"
- سيقوم النظام تلقائياً بـ:
  - حساب المستحقات لكل شريك
  - تحديد من دفع أكثر ومن دفع أقل
  - إنشاء التسويات المطلوبة
  - تحديث رصيد الخزينة

### 5. عرض التقارير

1. اضغط على "التقارير" من القائمة العلوية
2. اختر المرحلة المطلوبة
3. ستظهر لك:
   - أرصدة الشركاء
   - سجل المدفوعات
   - التسويات المطلوبة
   - رصيد الخزينة

## هيكل قاعدة البيانات

### الجداول الرئيسية:

- **stages**: المراحل
- **partners**: الشركاء
- **suppliers**: الموردين
- **payments**: المدفوعات
- **settlements**: التسويات
- **treasury**: الخزينة

## مثال عملي

### المدخلات:
- **المرحلة**: الأساسات - 10,000 جنيه
- **الشركاء**:
  - شريك أ: 50% - دفع 6,000 جنيه
  - شريك ب: 50% - دفع 4,000 جنيه
- **الموردين**:
  - مورد 1: دفع له 3,000 جنيه
  - مورد 2: دفع له 2,000 جنيه

### النتائج:
- **شريك أ**: دفع زيادة 1,000 جنيه
- **شريك ب**: دفع أقل 1,000 جنيه
- **التسوية**: شريك ب يدفع لشريك أ 1,000 جنيه
- **رصيد الخزينة**: 5,000 جنيه
