# دليل إعداد وتشغيل نظام إدارة مشاريع البناء

## نظرة عامة
نظام متكامل لإدارة مشاريع البناء مع إدارة المراحل، الشركاء، الموردين، المدفوعات، والتسويات المالية.

## المتطلبات الأساسية
- Node.js 18+ 
- PostgreSQL 14+
- npm أو yarn

## خطوات التثبيت والإعداد

### 1. تثبيت التبعيات
```bash
npm install
```

### 2. إعداد قاعدة البيانات

#### أ. إنشاء قاعدة بيانات PostgreSQL
```sql
CREATE DATABASE construction_projects;
```

#### ب. إعداد متغيرات البيئة
أنشئ ملف `.env` في المجلد الرئيسي وأضف:
```env
DATABASE_URL=postgresql://username:password@localhost:5432/construction_projects
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-secret-key-here
```

#### ج. تشغيل migration لقاعدة البيانات
```bash
npm run db:migrate
```

### 3. تشغيل التطبيق

#### وضع التطوير
```bash
npm run dev
```

#### وضع الإنتاج
```bash
npm run build
npm start
```

التطبيق سيعمل على: http://localhost:3000

## الميزات الرئيسية

### 1. إدارة المشاريع
- إنشاء مشاريع جديدة مع البيانات الأساسية
- إضافة مراحل متعددة لكل مشروع
- تحديد الشركاء ونسبهم في المشروع
- خزينة واحدة لكل مشروع

### 2. إدارة المراحل
- إضافة مراحل بتكاليف محددة
- ربط الموردين بكل مرحلة
- تتبع المدفوعات لكل مرحلة

### 3. إدارة الشركاء
- تسجيل الشركاء مع بياناتهم الكاملة
- تحديد نسب المشاركة في المشاريع
- حساب المبالغ المستحقة تلقائياً

### 4. إدارة الموردين
- تسجيل الموردين وبياناتهم
- ربط الموردين بالمراحل
- إدارة البنود والمواد لكل مورد

### 5. المدفوعات
- **القبض من الشركاء**: تسجيل المبالغ المستلمة من الشركاء
- **الصرف للموردين**: تسجيل المدفوعات للموردين
- تحديث الخزينة تلقائياً

### 6. التسويات
- حساب التسويات التلقائية بين الشركاء
- عرض الأرصدة (دائن/مدين) لكل شريك
- إنشاء وإدارة التسويات

### 7. التقارير المالية
- تقارير شاملة عن المشاريع
- تقارير الشركاء والموردين
- تقارير الخزينة والتسويات
- إمكانية التصدير لـ PDF و Excel

## هيكل قاعدة البيانات

### الجداول الرئيسية:
- `projects`: المشاريع
- `phases`: مراحل المشاريع
- `partners`: الشركاء
- `project_partners`: ربط الشركاء بالمشاريع
- `suppliers`: الموردين
- `phase_suppliers`: ربط الموردين بالمراحل
- `materials`: البنود والمواد
- `partner_payments`: مدفوعات الشركاء
- `supplier_payments`: مدفوعات الموردين
- `settlements`: التسويات
- `treasury_logs`: سجل الخزينة

## سير العمل

### 1. إنشاء مشروع جديد
1. انتقل إلى "المشاريع" > "مشروع جديد"
2. أدخل البيانات الأساسية للمشروع
3. أضف المراحل المطلوبة
4. حدد الشركاء ونسبهم (يجب أن يكون المجموع 100%)
5. احفظ المشروع

### 2. إدارة المدفوعات
1. **قبض من شريك**: 
   - انتقل إلى "المدفوعات" > "قبض من شريك"
   - اختر الشريك والمشروع
   - أدخل المبلغ وطريقة الدفع
   
2. **صرف لمورد**:
   - انتقل إلى "المدفوعات" > "صرف لمورد"
   - اختر المورد والمرحلة
   - أدخل المبلغ وطريقة الدفع

### 3. حساب التسويات
1. انتقل إلى "التسويات"
2. اختر المشروع
3. النظام سيحسب تلقائياً:
   - من دفع أكثر من حصته (دائن)
   - من دفع أقل من حصته (مدين)
   - التسويات المطلوبة بينهم

### 4. عرض التقارير
1. انتقل إلى "التقارير"
2. اختر نوع التقرير المطلوب
3. حدد الفترة الزمنية والمشروع
4. يمكنك تصدير التقرير أو طباعته

## الملفات المحدثة الرئيسية

### قاعدة البيانات
- `lib/db/postgres-schema-updated.sql`: المخطط الكامل لقاعدة البيانات
- `lib/db/models.ts`: نماذج TypeScript
- `lib/db/migrate.ts`: أداة migration

### الصفحات المحسنة
- `app/projects/new/enhanced-page.tsx`: صفحة إنشاء مشروع متكامل
- `app/settlements/enhanced-page.tsx`: صفحة التسويات المتقدمة
- `app/reports/enhanced-page.tsx`: صفحة التقارير الشاملة

## النصائح والممارسات الجيدة

1. **النسب**: تأكد أن مجموع نسب الشركاء = 100%
2. **المدفوعات**: سجل جميع المدفوعات فور حدوثها
3. **التسويات**: قم بإجراء التسويات بعد كل مرحلة أو شهرياً
4. **النسخ الاحتياطي**: قم بعمل نسخ احتياطية دورية لقاعدة البيانات
5. **التقارير**: راجع التقارير بانتظام لمتابعة الوضع المالي

## استكشاف الأخطاء

### مشكلة الاتصال بقاعدة البيانات
- تأكد من تشغيل PostgreSQL
- تحقق من صحة DATABASE_URL في ملف .env
- تأكد من وجود قاعدة البيانات

### مشكلة في المدفوعات
- تحقق من أن الشريك/المورد مرتبط بالمشروع/المرحلة
- تأكد من وجود رصيد كافي في الخزينة للصرف

### مشكلة في التسويات
- تأكد من تسجيل جميع المدفوعات
- تحقق من صحة النسب للشركاء
